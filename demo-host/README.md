# 연의기록 무료 배포

Vercel에서 기존 `yeontaro` 저장소를 가져오고 Root Directory를 `demo-host`로 선택한 뒤 Deploy를 누릅니다. 프로젝트 이름은 `yeon-record`를 권장합니다. 유료 옵션이나 도메인 구매는 필요하지 않습니다. 기본 vercel.app 주소의 실제 이름은 배포 후 할당 결과를 확인하세요.

기존 공개 데모의 검증된 정적 파일을 빌드할 때 복사합니다. 매 요청마다 기존 사이트를 프록시하지 않습니다. 111개 파일의 SHA-256을 확인한 뒤 배포하므로 기존 사이트 내용이 변경되면 새 버전의 manifest도 갱신해야 합니다. 현재 고정 버전의 카드 선택·팔로우 무료 공개·기록 저장 기능이 그대로 포함됩니다.
